# Security policy

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue or on Discord:

1. Use **"Report a vulnerability"** in the *Security* tab of the affected repository (GitHub private
   vulnerability reporting), or
2. write to **admin@kog.tw**.

Please tell us what you found, where, how to reproduce it and what it could be used for. Do not
include other people's personal data; a description is enough.

## What to expect

- We confirm that we have your report as soon as a person has read it.
- We tell you what we decided, and when it is fixed we say so.
- We do not run a bounty programme, but we are glad to credit you if you want to be named.

## Scope

The servers, accounts and website of King of Gores (`kog.tw`) and the code in the repositories of
this organisation. Please do not test with denial-of-service, spam or social engineering, do not
touch other players' accounts, and stop as soon as you can show the problem.
